Why open source matters here. A Messenger app holds your Facebook login and sees every message you send and receive. fMess's code is public, so you, or anyone, can check what it does with them and build it yourself. With a closed-source app, you take the developer's word for it.

Questions

Is fMess made by Meta?

No. It's an independent, open-source app that shows facebook.com/messages in its own window.

Why not messenger.com?

Meta shut it down in April 2026. Chats now live inside facebook.com.

Is it safe to sign in?

You sign in on Facebook's own page. fMess never sees your password and has no server.

Do encrypted chats work?

Yes: chats, calls on macOS, photos and voice messages.

My work computer doesn't allow installing apps?

On Windows, use the portable fMess: one .exe that runs without installing and needs no admin rights. Keep it anywhere, in Downloads or on a USB stick, and open it. When there is a new version, fMess opens its download; use the new file in place of the old one. On a Mac, the app from the .dmg also runs from any folder.

Windows says it can't find the WebView2 Runtime?

fMess uses WebView2, the part of Windows that shows web pages in apps. Windows 10 and 11 come with it, but some trimmed-down builds remove it. Install it from Microsoft's WebView2 page (the Evergreen installer), then open fMess again.
